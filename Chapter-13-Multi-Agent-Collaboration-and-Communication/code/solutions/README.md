# Chapter 13 Exercise Solutions

Use this folder as a navigator. Each exercise now lives in its own subfolder, with the exercise README and the runnable solution side by side.

## Exercise Guides

- [Exercise 1 README](exercise-1-team-selection/README.md): choose the travel team and explain why each role belongs.
- [Exercise 2 README](exercise-2-supervisor-routing/README.md): route messages to the correct agent based on the envelope.
- [Exercise 3 README](exercise-3-conflict-handling/README.md): resolve conflicting advice with one deterministic rule.
- [Exercise 4 README](exercise-4-failure-recovery/README.md): recover from temporary failure with retries and checkpoint/resume.

## Shared Prerequisites

- Python available on your machine.

The runnable exercises use only the Python standard library, so no dependency installation is required.

The per-exercise READMEs contain the exact run commands and expected output for each example. The runnable scripts live inside the matching exercise folders.
